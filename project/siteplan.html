Site Plan: Local Cycling Community & Route Hub

Project Proposal & Wireframes

Site Name

Proposed Name: VeloHub Local

Reason: I chose a cycling website because it connects my love for the sport with building clean, fast websites. From a coding perspective, this project lets me practice using modern HTML and CSS (like Flexbox and Grid) to organize real-world information. It gives me a great chance to design a site that looks good on any screen and makes it easy for riders to find routes, check gear, and connect with other cyclists.

Scenarios

➤

Where can I find a weekend gravel route under 30 miles with low elevation gain for a beginner group ride?

➤

When is the next local charity cycling event or group ride happening, and how do I sign up?

Color Scheme

Primary: #1E293B

Used for headers, primary text, and dark structural containers.

Secondary: #10B981

Accent/Interactive elements like CTA buttons, active links, and route difficulty flags.

Accent: #F8FAFC

Clean background canvas to ensure high-contrast text and vibrant route images.

Typography

Headings & Body: Montserrat (Sans-Serif) - Selected for its clean, modern athletic aesthetic and crisp readability across all viewport screens.

Technical Labels/Stats: Space Mono (Monospaced) - Used specifically for displaying route telemetry data (Distance, Elevation, GPS coordinates).
